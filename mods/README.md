# Mods
Cada pasta em `mods/` com um `mod.txt` vira uma aba própria no inventário criativo. Como no Java (Forge), as abas dos mods ficam em páginas de 10 (5 em cima, 5 embaixo), com os botões `<` `>` e o contador `1 / N` acima do menu; Pesquisar e Inventário aparecem em todas as páginas.
Veja `exemplo/mod.txt`. Texturas 16x16 opcionais em `textures/` (`<id>.png`, `<id>_top.png`, `_side`, `_bottom`).
Limite: 136 blocos+itens somando todos os mods. `/give` também aceita os nomes dos mods.
