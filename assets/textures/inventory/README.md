# Inventário

Texturas exclusivas da tela de inventário. Todas são PNG e podem ser editadas sem recompilar:

- `panel.png` — painel principal do inventário
- `slot.png` — slot normal
- `slot_selected.png` — slot selecionado
- `slot_hover.png` — slot sob o mouse
- `dim.png` — camada escura atrás do inventário

- `header.png` — faixa superior/área de preview
- `tooltip.png` — fundo do nome do item
